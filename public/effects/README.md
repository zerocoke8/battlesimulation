# public/effects — 스킬 이펙트 에셋 폴더

도트 모드 전투 화면이 쓰는 **스킬 이펙트 시트**를 넣는 곳이다.
여기에 파일을 넣으면 코드 수정 없이 코드 생성 임시 이펙트를 대체한다. 비어 있으면 임시 이펙트가 나온다.

**제작 규격은 [../../docs/EFFECTS.md](../../docs/EFFECTS.md) 에 있다. 그림을 그리기 전에 반드시 읽을 것.**
(캐릭터 스프라이트는 `public/sprites/` 이고 규격은 `docs/SPRITES.md` 다. 여기와 다른 폴더다.)

**만들 키의 최신 목록은 `npm run effects:list`** 로 뽑는다. 키마다 프레임 크기·시트 크기·프레임 수·fps·재생 시간·blend·loop·anchor·쓰임이
전부 나오므로 그 표만 보고 그려도 된다. 장판 테두리(`zone_ring_<계열>_r<반경×10>`)는 게임 데이터의 스킬 반경에서 자동으로 만들어져
밸런싱 때마다 바뀌니, 작업 시작 전에 한 번 돌려 확인한다.

## 넣는 법

키 하나당 파일 두 개를 이 폴더에 **바로** 넣는다 (하위 폴더를 만들지 않는다).

```
public/effects/impact_fire.png     시트 이미지 — 한 줄(1행), 왼쪽 → 오른쪽
public/effects/impact_fire.json    메타데이터
```

`impact_fire.json` 예 (값은 `docs/EFFECTS.md` §4 의 키별 표에서 그대로 옮긴다):

```json
{
  "frameW": 64,
  "frameH": 64,
  "frames": 6,
  "fps": 20,
  "anchor": { "x": 32, "y": 32 },
  "blend": "add",
  "loop": false
}
```

- PNG 크기는 정확히 `frameW × frames` 폭 × `frameH` 높이여야 한다. 위 예는 **384 × 64**.
- 알파는 **0 또는 255 만** (반투명 픽셀 금지, 안티앨리어싱·블러 금지).
- 파일 이름 = 키 이름. 키 목록(현재 68종)은 `npm run effects:list` · `docs/EFFECTS.md` §4, 코드 쪽 정의는 `src/ui/pixel/fx/fxTypes.ts` 의 `FX_KEYS`.
- 장판 테두리는 반경마다 크기가 다르다 — 프레임 한 변 = `반경 × 2 × 32 px` 의 정사각형이고 시트 폭은 그 4배(4프레임).
  예: `zone_ring_fire_r35` (반경 3.5) = 프레임 224×224, 시트 **896 × 224**. 늘리거나 이어 붙이지 않고 그 크기로 딱 맞게 그린다.
- **일부 키만 넣어도 된다.** 넣은 키만 제작 에셋으로 바뀌고 나머지는 임시 이펙트가 계속 나온다.
  넣는 순서는 `docs/EFFECTS.md` §6 의 우선순위(1순위 21종 → 2순위 40종 → 3순위 7종)를 따른다.
- JSON 이 없으면 기본 메타(`FX_DEFAULT_META`)로 읽는다. PNG 가 없으면 그 키는 임시 이펙트로 남는다.

## 확인

```
npm run effects:list     무엇을 만들어야 하는지 (키·크기·프레임·fps·초·blend·loop·anchor·쓰임)
npm run effects:check    만든 것이 규격에 맞는지
```

검사기는 키 이름·PNG 크기·JSON 필드·알파 0/255 를 보고, 여기에 더해
`zone_fill_*` 은 **좌우·상하 이음매**, `zone_ring_*` 은 **크기**(프레임 한 변 = 반경 × 64, 시트 폭 = 한 변 × 프레임 수)를 검사한다.
파일이 하나도 없으면 "아직 제작 에셋 없음 (임시 이펙트 사용 중)" 으로 통과한다.

화면에서 보려면 `npm run dev` 로 띄우고 도트 모드(기본)로 전투를 관전한다. 파일을 바꾼 뒤에는 새로고침한다.

## 이 폴더에 넣지 않는 것

- 캐릭터·몬스터·소환물 스프라이트 → `public/sprites/`
- 편집 가능한 원본(.aseprite 등) → `art/aseprite/`
- 하위 폴더·규격 밖 파일은 로더가 무시하고 검사기가 경고한다.
