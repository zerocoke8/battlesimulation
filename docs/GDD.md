## 1. 개요

- 장르: 관전형 팀 육성 시뮬레이션 (풋볼 매니저 26 모바일의 관전 방식 + 우마무스메식 육성 + 로그라이크 선택지)
- 세계관: 이능이 존재하는 판타지 세계. 4인 팀이 맵 위에서 실시간으로 싸운다.
- 플레이어 역할: 전투 중 개입 없음. 전투 전후의 육성 선택으로만 팀을 만든다.
- 육성 목표: 10일의 육성을 거쳐 4인 팀을 완성한다.
- 완성된 팀의 용도: 다른 유저의 완성 팀과 PvP, 점수 경쟁 레이드 등 PvE.
- 계승/인자 같은 영구 성장 요소는 없다. 육성은 매번 완전히 초기화된다.
- 검증 방식: 웹 브라우저 기반 시뮬레이터로 먼저 검증한다.

## 2. 핵심 루프

```
[가챠 풀에서 4명 선택]
        │
        ▼
┌──────────────────── 하루 (×10일) ────────────────────┐
│ 1스텝  로그라이크 선택지 3장 중 1장                  │
│ 2스텝  로그라이크 선택지 3장 중 1장                  │
│ 3스텝  몬스터 전투 (하급/중급/고급 중 난이도 선택)   │
│ 4스텝  로그라이크 선택지 3장 중 1장                  │
│ 5스텝  4:4 전투 (생성 상대 또는 같은 일차의 고스트)  │
│   ▼                                                  │
│ 하루 마무리 — 보상 요약 + 보너스 상점                │
└──────────────────────────────────────────────────────┘
        │
        ▼
[팀 완성] → PvP / PvE 레이드에 사용
```

- 스텝 순서는 고정이다. 하루는 항상 선택 · 선택 · 몬스터 · 선택 · 전투 다섯 스텝이다.
- 5스텝이 끝나면 '하루 마무리' 화면(보상 요약 + 보너스 상점)을 거쳐 다음 날 1스텝으로 간다. 하루 마무리는 스텝으로 세지 않는다.
- 10일차 5스텝이 끝나면 육성 완료.
- 전투(몬스터·4:4 모두)에서 져도 진행은 계속된다. 승패는 보상 양과 보장 보상에만 영향을 준다.
- 육성 중 직업 분화, 스킬 습득, 팀 시너지가 결정되므로 같은 시작 4명이라도 매번 다른 팀이 된다.
- 하루에 선택지 3회 + 전투 2회 = 10일 동안 선택 30회, 전투 20회를 치른다.
- 팀 인원은 상수 `TEAM_SIZE = 4` 로 고정한다. 플레이어 팀 · 4:4 상대팀 · 고스트 · 완성팀은 정확히 4명이다. 몬스터 팀만 예외로 1~8명 (§7.3).

## 3. 직업 체계

### 3.1 메인 직업군 (9종)

| 메인 직업 | 역할 | 세부 직업 (확정) |
|---|---|---|
| 검사 | 근접 딜/브루저 | 대검사(광역), 쾌검사(속공), 마검사(마법 부여) |
| 탱커 | 전열 방어, 어그로 | 철벽(방패 방어), 가시갑옷(반사), 도발자(어그로 집중) |
| 버서커 | 근접 폭딜, 체력 소모형 | 광전사(체력 낮을수록 강함), 피의 계약자(흡혈), 파괴자(방어 무시) |
| 암살자 | 은신, 후방 침투, 단일 폭딜 | 그림자 암살자(은신), 독 암살자(지속 피해), 환영 암살자(분신) |
| 궁수 | 중거리 지속 딜 | 속사 궁수(연사), 정밀 궁수(치명), 함정 궁수(설치물) |
| 저격수 | 장거리 단발 고화력 | 관통 저격수(직선 관통), 마탄 저격수(마법탄), 감시자(시야/디버프) |
| 마법사 | 원거리 광역/제어 | 화염(광역 폭딜), 전기(연쇄/마비), 냉기(둔화/빙결) |
| 소환사 | 소환물로 전선 형성 | 야수 소환사(근접 소환물), 정령 소환사(원거리 소환물), 사령술사(적 시체 활용) |
| 힐러 | 회복, 지원 | 신관(직접 회복), 드루이드(지속 회복/자연), 결계사(보호막/버프) |

### 3.2 직업 분화 규칙

- 시작 시에는 메인 직업만 갖는다. 세부 직업은 육성 중 로그라이크 선택지로 분화한다.
- 분화 선택지는 4~6일차 사이에 각 캐릭터마다 1회 보장 등장한다. 세 세부 직업 중 하나를 고른다. (확정)
- `[제안]` 분화 후에도 "직업 변경" 선택지가 낮은 확률로 등장한다. 다른 세부 직업 또는 다른 메인 직업으로 변경할 수 있으나 스탯 일부를 잃는다.
- 세부 직업은 고유 스킬 1~2개와 스탯 보정을 갖는다.
- 4인 팀이므로 한 팀에 9개 직업 중 최대 4개만 들어간다. 역할 공백(탱커 없음, 힐러 없음 등)이 5인 때보다 자주 생기며, 이것이 편성의 개성이 된다.

### 4.2 파생 전투 수치 (기본 스탯에서 계산) `[제안 공식, 밸런싱 대상]`

| 전투 수치 | 공식 |
|---|---|
| 최대 HP | 600 + 체력² × 0.95 + 직업 보정 × 3 (체력에 초선형. 전투 시간 60~120초 목표에 맞춰 조정됨) |
| 물리 공격력 | 근력 × 1.0 + 숙련도 × 0.3 |
| 이능 공격력 | 마력 × 1.0 + 숙련도 × 0.3 |
| 물리 방어 | 방어기술 × 0.8 + 체력 × 0.2 |
| 이능 방어 | 저항 × 0.8 + 침착 × 0.2 |
| 공격 속도 | 기본 0.6 × (1 + 민첩 / 200) (v0.6 에서 1.0 → 0.6. 스킬 피해 비중을 올리기 위해 기본 공격 빈도를 낮춤) |
| 이동 속도 | 기본 3.0 × (1 + 이동속도 / 150) |
| 치명타 확률 | 집중 × 0.4 % |
| 치명타 배율 | 150 % + 치명 × 0.5 % |
| 적중률 | 70 % + (명중 − 상대 회피) × 0.3 % (하한 30%, 상한 100%) |
| 맵 보정 | 해당 맵 적응도 50 기준. (적응도 − 50) × 0.4 % 를 전투 수치 전체에 곱연산 (최대 ±20%) |

| 최대 MP | 50 + 마력량 × 2 |
| MP 회복 | 초당 1 + 마력회복 × 0.08 |
| 시전 속도 | 1 + 시전속도 / 200 (배율) |
| 쿨타임 감소 | 숙련도 × 0.4 % (상한 40%) |

- 피해 공식: `피해 = 공격력 × 스킬 계수 × (100 / (100 + 방어)) × 맵 보정 × 치명 배율`
- 맵 보정은 최대 HP, 공격력, 방어, 공격 속도, 이동 속도에 곱해진다. 확률과 사거리에는 적용하지 않는다.
- 빙결 상태의 대상은 받는 피해 +25%.
- 지구력: 전투 30초 경과 후부터 초당 지구력 기반으로 스탯이 서서히 감소한다. 지구력 100이면 감소 없음.

### 4.3 직업별 성장 성향

- 각 메인 직업은 스탯별 성장 계수(0.5~1.5)를 갖는다. 같은 선택지를 골라도 마법사는 마력이, 검사는 근력이 더 오른다.
- 세부 직업 분화 시 성장 계수가 한 번 더 보정된다.

### 4.4 광역 회피 (dodge) — 확정 공식

광역 스킬은 시전 완료 뒤 **예고(텔레그래프) 시간**이 지나야 효과가 적용된다 (§6.5). 예고가 시작되는 순간, 영역 안에 있는 적 유닛마다 **한 번** 회피 판정을 한다.

```
회피 확률 = clamp(판단력 × 0.006 + 민첩 × 0.003, 0.05, 0.85)
예고 시간 < 0.5초 이면 회피 확률 절반
```

- 기절·빙결 상태, 이동속도 0 (포탑류 소환물), 도발 상태인 유닛은 회피 불가.
- 판정은 **인지**만 결정한다. 성공한 유닛은 영역 경계 밖으로 가장 가까운 탈출점(+0.6 여유)을 목표로 잡고, 예고가 끝날 때까지 **이동속도 × 1.15** 로 그쪽으로만 움직인다. 시전 중이던 스킬은 취소된다 (MP 환불, 쿨타임 시작 안 함).
- 효과 적용(impact) 시점에 영역 밖이면 피해를 받지 않는다. 이동속도가 느려 못 벗어나면 그대로 맞는다.
  → 판단력·민첩은 "피하려는지", 이동속도는 "실제로 피하는지" 를 결정한다. 세 스탯이 전투에서 실제 의미를 갖게 하는 것이 이 공식의 목적이다.
- 기준값 (§11 보정 목표): 판단력 80 · 민첩 70 유닛은 예고 0.8초 광역을 절반 이상 피하고, 판단력 30 · 민첩 30 유닛은 30% 미만으로 피해야 한다.
  - 판단력 80 · 민첩 70 → 0.48 + 0.21 = 0.69 (인지). 이동속도 40 이상이면 대개 벗어난다.
  - 판단력 30 · 민첩 30 → 0.18 + 0.09 = 0.27 (인지). 느린 유닛은 인지해도 못 벗어나므로 실제 회피율은 이보다 더 낮다.
- 기술 카테고리의 '회피' 스탯은 단일 공격 적중률 계산에만 쓰이고, 광역 회피에는 관여하지 않는다.

## 5. 맵

맵은 전투마다(3스텝 몬스터 전투, 5스텝 4:4 전투) 그날의 시드로 결정된다. 각 맵은 지형 특성과 승리 조건을 가진다.

| 맵 | 특성 | 유리한 직업 | 승리 조건 (확정) |
|---|---|---|---|
| 평원 | 개활지. 장애물 없음. 시야 넓음 | 저격수, 궁수, 마법사 | 상대 전멸 |
| 어둠 | 시야 반경 축소. 은신 효과 증가 | 암살자, 소환사 | 상대 전멸 또는 제한시간 종료 시 잔여 HP 합 비교 (시야 때문에 서로 못 찾고 끝나는 무승부를 막기 위해) |
| 사막 | 지구력 소모 2배. 이동속도 저하 | 탱커, 힐러, 버서커 | 상대 전멸 또는 제한시간 종료 시 잔여 HP 합 비교 |
| 빙하 | 이동 시 미끄러짐(경로 오차). 냉기 이능 강화 | 냉기 마법사, 검사 | 중앙 거점 점령 (일정 시간 점유) 또는 전멸 |

- 맵 적응도는 육성으로 올릴 수 있다. 캐릭터는 초기 적응도가 랜덤하게 분포되어 있어 가챠 단계에서 차별점이 된다.
- 맵 크기 `[제안]`: 40 × 30 단위. 양 팀은 좌우 끝에서 시작한다.
- 맵 정의의 `spawnA / spawnB` 는 **대열 기준 열(anchor)** 이다. 실제 스폰 위치는 팀 인원 수(1~8)에 맞춰 시뮬레이션이 생성한다 (§7.3.2 대열 규칙).

## 6. 전투 시뮬레이션

### 6.1 기본 구조

- 실시간 이동 전투. 맵 위에서 캐릭터가 이동하며 자동으로 판단하고 싸운다.
- 결정론적 시뮬레이션: 시드값 + 양 팀 데이터가 같으면 누구의 기기에서 재생해도 완전히 동일한 결과가 나온다.
  - 시뮬레이션 로직은 고정 틱(예: 초당 20틱)으로 돌고, 렌더링과 분리한다.
  - 난수는 시드 기반 PRNG만 사용하고, 부동소수점 순서 문제를 피하기 위해 연산 순서를 고정한다.
  - 전투 기록은 `시드 + 팀 데이터`만 저장하면 재생 가능하다. 공유 및 리플레이가 쉽다.
- 틱 레이트: 초당 20틱 고정.
- 배속: 1배, 2배, 4배, 스킵 지원. 배속은 틱 진행 속도만 바꾸고 시뮬레이션 결과에는 영향이 없다.
- 소환물은 전멸 판정에 포함되지 않는다. 소환사가 죽어도 소환물은 지속시간까지 남는다.
- 지구력 감소: 30초 이후 초당 감소, 감소량은 (100 − 지구력)/100 에 비례하고 맵의 지구력 소모 배율을 곱한다. 총 감소 상한 30%.
- 전투 시간: 완성 팀 기준 평균 1~2분. 초반 육성 단계는 HP가 낮아 더 빨리 끝난다. `[제안]` 제한시간 3분, 초과 시 맵별 규칙으로 판정.
- 시뮬레이션은 어느 쪽 팀이든 **1~8명**을 스폰할 수 있어야 한다. 4:4 는 플레이어 전투의 규칙이고 시뮬레이션의 제약이 아니다.

### 6.2 AI 행동

캐릭터 AI는 직업 기본 행동 + 정신 스탯의 영향으로 결정된다.

- 직업 기본 행동: 탱커는 전진하여 적 근접, 암살자는 우회하여 후방 딜러 노림, 힐러는 아군 뒤에서 체력 낮은 아군 회복, 저격수는 최대 사거리 유지 등.
- 판단력: 높을수록 최적 타겟(체력 낮은 적, 위험한 적)을 고른다. 낮으면 가장 가까운 적을 친다. 광역 예고를 인지하고 피할 확률에도 관여한다 (§4.4).
- 용기: HP 30% 이하일 때 후퇴 여부를 결정.
- 협동: 아군 근처 위치 선정 및 시너지 스킬 발동 확률.
- 회피 이동 중(§4.4)에는 다른 행동을 하지 않는다. 예고가 끝나면 원래 행동 판단으로 돌아간다.
- 스킬 선택: 쿨타임·MP·대상·조건을 모두 만족하는 스킬이 여럿이면 슬롯 순서가 아니라 **MP 소모가 가장 큰 스킬**을 먼저 쓴다. 메테오처럼 비싼 대표기가 싼 스킬에 밀려 발동하지 못하는 일을 막기 위한 규칙이다. 동률이면 슬롯 순서.


### 6.3 관전 화면

- FM26 모바일처럼 단순한 원형 아이콘 + 직업 심볼로 캐릭터를 표시한다.
- 화면 요소: 맵, 캐릭터 아이콘, HP 바, 스킬 발동 이펙트(간단), **광역 영역 표시(§6.5)**, 경과 시간, 킬 로그, 배속 버튼.
- 몬스터 유닛은 플레이어 캐릭터와 구분되게 그린다 (난이도별 색/외곽선, 몬스터 종류 표시). `Character.monster` 가 있으면 몬스터다.
- 전투 후 결과 화면: 승패, 킬/데스, 딜량, 힐량, MVP.
- **스킬명 외치기 (v0.6)**: 스킬 시전 시 시전자 머리 위에 「메테오!」 같은 말풍선을 띄운다. 흰 바탕에 팀 색 테두리, 0.15초 팝 후 1.2초 동안 위로 떠오르며 사라진다. 광역·장판 스킬은 글씨가 더 크고 테두리가 두껍다. 시전자 원은 0.2초 동안 1.25배로 커졌다 돌아온다. 킬 로그에도 '이름: 스킬명!' 줄을 최근 3개까지 남긴다. 연출 시간은 시뮬레이션 시간 기준이라 배속과 무관하게 같다.


### 6.4 진행 표시 HUD (확정)

육성 중 어느 화면에서든 현재 위치를 잃지 않게 하는 고정 표시. **전투 관전 중에도 계속 보인다.**

- 위치: 화면 **왼쪽 위 고정**. 전투 맵·카드 UI를 가리지 않는다.
- 내용
  - `N일차` 와 `M/5` (현재 스텝 번호)
  - 5개의 스텝 칩: 선택 · 선택 · 몬스터 · 선택 · 전투. 현재 스텝은 강조, 이미 지난 스텝은 흐리게, 남은 스텝은 기본색.
  - 보유 보너스 포인트
  - 팀 전투력 (팀 전체 파생 수치 기반 요약값)
- 반응형: **400px 폭에서도 화면을 가리지 않아야 한다.** 좁은 화면에서는 칩 크기와 여백을 줄여 한 줄을 유지한다.
- 하루 마무리(`day_end`)와 팀 선택(`select_team`) 화면에서는 스텝 칩 대신 해당 상태를 표시한다.

### 6.5 광역 스킬: 범위 표시 · 예고 · 장판 (확정)

광역 스킬은 "시전 → 즉시 적용" 이 아니라 **"시전 → 영역(Zone) 생성 → 예고 → 적용(impact) → (장판)"** 순서로 진행된다. 관전자는 어디에 무엇이 떨어질지 미리 보고, 유닛은 그것을 피하려 움직인다.

#### 6.5.1 스킬 데이터

`SkillDef` 에 선택 필드 두 개가 추가된다.

| 필드 | 의미 |
|---|---|
| `telegraphSec` | 예고 시간(초). 시전 완료 후 이 시간이 지나야 효과가 적용된다 |
| `linger` | 장판. `{ durationSec, dpsCoef, status? }`. 예고 뒤 영역이 남아 안의 적에게 초당 피해와 상태를 준다 |

예고 기본값 (필드 생략 시):

| 스킬 종류 | 기본 예고 | 상수 |
|---|---|---|
| 대상 `enemy_area` / `line` 인 피해 스킬 | 0.8초 | `DEFAULT_TELEGRAPH_SEC` |
| 시전자 중심 소형 근접 광역 (radius ≤ 2.5 이고 range ≤ 2) | 0.3초 | `SHORT_TELEGRAPH_SEC` |
| 아군 광역 `ally_area` | 예고 없음(즉시). 0.4초짜리 표시용 영역만 남긴다 | `ALLY_AREA_FLASH_SEC` |

#### 6.5.2 Zone 런타임

시전 완료 시점에 효과를 바로 적용하지 않고 Zone 을 만든다.

```
Zone { id, side, casterId, skillId, shape: 'circle' | 'line',
       x, y, radius, x2?, y2?, width?,
       telegraphRemainingSec, lingerRemainingSec, impactDone }
```

- **예고(telegraph)**: `telegraphRemainingSec` 이 0 이 되는 틱에 영역 안의 대상에게 스킬 효과(피해·상태·넉백 등)를 적용한다. 이것이 impact.
- **장판(linger)**: `linger` 가 있으면 impact 뒤 `durationSec` 동안 영역이 남고, 매 틱 `dpsCoef × 시전자 공격력 × dt` 의 피해(방어 적용)와 `status` 를 안의 적에게 준다.
- 시전자가 예고 도중 죽어도 Zone 은 유지된다. 이미 던져진 마법은 취소되지 않는다.
- Zone 처리 순서는 생성 순서 고정. 결정론을 위해 배열로 관리한다.
- `line` 형태는 시전자 위치 → 목표 지점의 선분(`x,y` → `x2,y2`) 과 폭 `width` 로 정의한다.

#### 6.5.3 회피

Zone 생성 시(예고 시작) 영역 안의 적 유닛마다 한 번 판정한다. 공식과 규칙은 §4.4. 예고 없는 스킬(`telegraphSec = 0`)은 회피 판정을 하지 않는다.

#### 6.5.4 프레임과 이벤트

- `BattleFrame.zones: ZoneSnapshot[]` — `{ id, side, skillId, shape, x, y, radius, x2?, y2?, width?, phase, progress, remainingSec }`.
  - `phase`: `'telegraph'`(예고 중) · `'active'`(장판 지속 중) · `'flash'`(impact 직후 0.25초, `ZONE_FLASH_SEC`, 폭발 표시용).
  - `progress`: 현재 단계 진행률 0~1.
- `BattleEvent` 추가: `{ kind: 'zone'; from; skillId; x; y }` (Zone 생성), `{ kind: 'dodge'; unit; skillId }` (회피 성공).
- (v0.6) 피해 출처: `attack` 이벤트에 `skillId?` (스킬 피해면 있음, 기본 공격이면 없음). 장판 틱은 `{ kind: 'zone_damage'; from; to; skillId; damage; school }`,
  화상·중독 틱은 `{ kind: 'dot'; from; to; status; damage }`, 반사는 `{ kind: 'reflect'; from; to; damage }`. `zone_damage`/`dot` 는 프레임 이벤트에만 실린다.
  헤드리스 도구가 이것으로 스킬 피해 비중(목표 10일차 55~70%)을 잰다.

#### 6.5.5 렌더

| 단계 | 표현 |
|---|---|
| 예고 | 시전자 팀 색 **점선 테두리** + 안쪽이 진행률(`progress`)만큼 채워지는 원 / 직사각형 |
| 폭발(flash) | 밝은 플래시. 0.25초 |
| 장판(active) | 반투명 채움 + 가장자리 흐름 효과 |
| 회피 성공 | 해당 유닛 위에 **'회피!'** 텍스트 |

#### 6.5.6 밸런스 원칙

- 예고 때문에 광역이 약해지는 만큼, 광역 피해 계수를 **1.15~1.3배** 올리는 것을 허용한다 `[제안]`. 최종값은 보정 단계(§11)에서 정한다.
- 장판형 스킬은 즉발 피해를 낮추고 `linger` 로 총 피해를 채운다. 자리를 지켜야 하는 거점 맵(빙하)에서 강해지는 것이 의도다.
- 8기 떼 몬스터(§7.3)는 광역의 가치를, 1기 보스의 강한 광역 장판은 회피와 이동속도의 가치를 보여주는 역할을 맡는다.

## 7. 육성 시스템

### 7.1 시작: 가챠와 팀 선택

- 가챠로 뽑은 캐릭터 풀에서 4명을 직접 고른다. (`select_team`, 0일차 0스텝)
- 프로토타입에서는 랜덤 생성된 캐릭터 풀을 미리 마련해 두고 그중 4명을 고르는 방식으로 대체한다.
- 캐릭터 생성 요소: 메인 직업, 초기 스탯(직업 성향 기반 랜덤), 초기 맵 적응도(랜덤 20~80), 성장 성향(랜덤 소폭 편차 0.85~1.15), 초기 스킬 1개, 등급(스탯 총합 기반 1~5성, 표시용).
- 프로토타입 풀 크기: 24명. 9개 직업이 최소 2명씩 포함된다.

### 7.2 하루의 구성 (확정)

**하루 = 5스텝, 총 10일.** 스텝 순서는 고정이며 건너뛰거나 바뀌지 않는다.

| 스텝 | 내용 | RunPhase |
|---|---|---|
| 1 | 로그라이크 선택지 3장 중 1장 | `choice` |
| 2 | 로그라이크 선택지 3장 중 1장 | `choice` |
| 3 | 몬스터 전투 — 난이도 3장 중 1장 선택 후 관전 | `monster_select` → `monster_battle` |
| 4 | 로그라이크 선택지 3장 중 1장 | `choice` |
| 5 | 4:4 전투 — 맵·상대 공개 후 관전 | `pre_battle` → `battle` |
| — | 하루 마무리: 보상 요약 + 보너스 상점 | `day_end` |

- `day_end` 는 스텝이 아니다. 5스텝이 끝나면 반드시 거치고, 나가면 다음 날 1스텝으로 간다.
- 10일차의 `day_end` 를 나가면 `done` (육성 완료).
- 상수: `TOTAL_DAYS = 10`, `STEPS_PER_DAY = 5`, `CHOICE_STEPS = [1,2,4]`, `MONSTER_STEP = 3`, `BATTLE_STEP = 5`, `TEAM_SIZE = 4`.

#### 하루 마무리 (`day_end`)

- 그날의 보상 요약: 몬스터 전투 결과와 보상, 4:4 전투 결과와 보상, 고른 선택지 목록(희귀도 포함), 획득 포인트 합계.
- 보너스 상점에서 포인트를 쓴다.
  - 스킬 구매 (직업 스킬 상점, 스킬당 60~150 포인트 `[제안]`)
  - 스탯 소폭 성장 (30 포인트에 한 스탯 +4 `[제안]`)
  - 선택지 리롤권 (하루 1회, 40 포인트 `[제안]`)
- 4:4 전투 포인트 `[제안]`: 승리 120, 무승부 80, 패배 50. 일차가 올라갈수록 소폭 증가.

### 7.3 몬스터 전투 (3스텝, 확정)

플레이어가 **난이도를 직접 고르는** PvE 스텝. 위험과 보상을 저울질하는 것이 이 스텝의 재미다.

#### 7.3.1 난이도와 목표 승률

| 난이도 | `MonsterTier` | 목표 승률 (표준 성장 플레이어 기준) |
|---|---|---|
| 하급 | `low` | 95~100% |
| 중급 | `mid` | 80% (75~85) |
| 고급 | `high` | 50% (45~55) |

- 목표 승률은 헤드리스 대량 시뮬레이션으로 보정한다. "표준 성장 플레이어" = 매 선택지를 무작위로 고르고 보너스를 기본 정책으로 쓴 팀.
- 스탯 상한(100) 때문에 후반 일차에서 난이도를 더 못 올리는 문제를 피하기 위해, 몬스터는 `Character.derivedMult` (파생 수치 최종 배율)로 강도를 올린다. 플레이어 캐릭터에는 쓰지 않는다.
- 일차별 승률 곡선은 평평해야 한다. 같은 난이도 안에서 1기 보스와 8기 떼의 승률 편차는 **±8%p 이내** 로 맞춘다.

#### 7.3.2 몬스터 종류와 인원

- 난이도마다 최소 4종, 총 12종 이상. 한국어 이름·설명·편성이 서로 달라야 한다.
- 몬스터 팀 인원은 **1~8명** (`MONSTER_TEAM_MIN = 1`, `MONSTER_TEAM_MAX = 8`). 플레이어 팀은 항상 `TEAM_SIZE = 4` 명이지만 몬스터는 4:4 에 구애받지 않는다.
- **인원 패턴은 난이도마다 골고루**: 각 난이도에 1~2명 / 3~4명 / 6~8명 편성이 모두 있어야 한다. 예: 고급 '고대 골렘' 1기 단독(강한 광역 장판), 하급 '슬라임 무리' 8기, 중급 '오크 전사대' 4기.
- 몬스터 유닛도 기존 `MainJob` 중 성향이 맞는 직업을 쓴다. AI 행동을 그대로 재사용하기 위함이다. (예: 슬라임 = 탱커, 하피 = 궁수, 리치 = 마법사)

| 난이도 | 편성 성격 | 예시 |
|---|---|---|
| 하급 | 약한 다수 또는 약한 소수 | 슬라임 무리(8), 들개 떼(6), 고블린 정찰조(3~4), 동굴 박쥐 떼(2) |
| 중급 | 균형잡힌 편성 | 오크 전사대(4), 하피 무리(6), 리빙 아머(2), 도적단(3~4) |
| 고급 | 강한 보스 1기, 보스 + 수하, 또는 강한 6~8기 | 고대 골렘(1, 광역 장판), 서리 드래곤(1), 리치 + 스켈레톤(1+5), 심연의 마수 무리(6~8) |

**대열(formation) 규칙** — 확정. 맵의 `spawnA / spawnB` 는 기준 열(anchor)만 제공하고, 시뮬레이션이 인원 수에 맞는 위치를 결정론적으로 생성한다.

- 전열(탱커·근접: `tank`, `melee_dps`, `assassin`(근접 시작), `berserker`)은 상대 쪽에 가깝게, 후열(원거리·힐러·마법사·소환사)은 기준 열 뒤에 세운다.
- 각 열 안에서는 세로(y)로 균등 분포. 대열 중심은 기준 열의 y 평균.
- 맵 경계 안에 들어가야 하고 유닛끼리 겹치지 않는다 (최소 간격 `[제안]` 1.5 단위). 8명이면 한 열에 최대 4~5명, 넘치면 열을 하나 더 만든다.
- 결정론: 같은 팀 데이터·같은 맵이면 항상 같은 위치. 난수를 쓰지 않는다.
- 이 규칙은 플레이어 4인 팀에도 동일하게 적용된다.

#### 7.3.3 선택 화면

- 카드 3장 = 하급/중급/고급 각 1장. 각 난이도에 어떤 종이 나올지는 **그날의 시드**로 결정된다.
- 카드에 표시할 것: 몬스터 이름과 설명, 편성(유닛 종류 × 수, 총 인원), 예상 난이도, 보상, 전투가 벌어질 맵.

#### 7.3.4 보상 `[제안]`

| 난이도 | 승리 보상 |
|---|---|
| 하급 | 포인트 60 + 일차 × 6 |
| 중급 | 포인트 120 + 일차 × 10, 다음 선택지에 '레어 이상' 1장 보장 |
| 고급 | 포인트 220 + 일차 × 16, 다음 선택지에 '에픽 이상' 1장 보장, 팀 전원 랜덤 스탯 +3 |

- 패배 시: 포인트만 40% 지급. 보장 등급과 추가 보상 없음.
- 패배해도 진행은 계속된다. 다음 스텝(4스텝 선택지)으로 그대로 넘어간다.

### 7.4 선택지 희귀도 (확정)

| 희귀도 | `ChoiceRarity` | 색 |
|---|---|---|
| 일반 | `common` | 회색 `#9aa3ad` |
| 레어 | `rare` | 파랑 `#4a9eff` |
| 에픽 | `epic` | 보라 `#a563f0` |
| 전설 | `legendary` | 황금 `#f0b429` |

- **생성 순서**: 먼저 카드별 희귀도를 뽑고, 그 희귀도에 맞는 크기로 효과를 만든다. (효과를 만든 뒤 등급을 붙이지 않는다)

#### 7.4.1 희귀도 가중치 `[제안]`

| 일차 | 일반 | 레어 | 에픽 | 전설 |
|---|---|---|---|---|
| 1~3일 | 52 | 32 | 13 | 3 |
| 4~7일 | 44 | 34 | 17 | 5 |
| 8~10일 | 34 | 35 | 22 | 9 |

#### 7.4.2 희귀도별 효과 크기 `[제안]`

| 희귀도 | 총 스탯 상승량 기준 |
|---|---|
| 일반 | 10~16 |
| 레어 | 20~30 |
| 에픽 | 36~50 |
| 전설 | 60~85 |

- 이 기준은 4인 팀에서도 유지한다. 인원이 줄어 한 명당 배분이 늘어나지만 총량 기준은 바꾸지 않는다.
- 트레이드오프·도박형은 하락·실패 위험을 지는 대신 같은 희귀도에서 상승량을 최대 1.4배까지 준다.
- 스킬 습득은 스킬 가격으로 등급을 본다. 시너지는 레어~에픽, 직업 분화는 항상 에픽으로 본다.

#### 7.4.3 보장 등급 (`rarityFloor`)

- `RunState.rarityFloor` 에 값이 있으면, 다음에 생성되는 선택지 3장 중 **최소 1장이 그 등급 이상**이어야 한다. 사용하면 `null` 로 돌아간다.
- 몬스터 중급/고급 승리가 이 값을 채운다.

#### 7.4.4 예상 전투력 상승치 (`powerDelta`)

- 각 카드에 예상 전투력 상승치를 표시해 비교를 돕는다. `estimatePowerDelta(team, choice)` (choices.ts) 로 계산한다.
- 가중치 `[제안]`: 스탯 1 = 1, 스킬 = 25, 시너지 = 20, 직업 분화 = 35, 맵 적응 1 = 0.4.

### 7.5 로그라이크 선택지 종류

| 종류 | 예시 | 비고 |
|---|---|---|
| 단일 대폭 성장 | A의 근력 +15 | |
| 다수 소폭 성장 | A, B의 민첩 +6 | |
| 트레이드오프 | A, B, C 각 +8, D는 체력 −6 | 이득이 큰 대신 누군가 손해 (4인 팀에서는 3명 상승 + 1명 하락) |
| 도박형 | 70% 확률로 A 마력 +20, 실패 시 −5 | 실패 가능. 성공 확률은 화면에 표시 |
| 스킬 습득 | A가 새 스킬 습득 | 직업에 맞는 스킬 풀에서 |
| 직업 분화 | A를 화염/전기/냉기 중 하나로 분화 | 4~6일차 사이 캐릭터당 1회 보장 |
| 직업 변경 | A를 다른 직업으로 변경, 스탯 −10% | 낮은 확률 등장 |
| 맵 적응 훈련 | 팀 전체 사막 적응도 +8 | |
| 팀 시너지 | A와 B가 인접 시 공격력 +10% 시너지 획득 | |
| 희생형 | A가 스킬 1개를 포기하는 대신 팀 전체 스탯 +5 | 다른 캐릭이 무언가를 포기 |

- 한 세트는 3장이며 서로 다른 종류가 나오도록 한다.
- `[제안]` 후반 일차로 갈수록 대형 성장·시너지 비중이 높아진다 (희귀도 가중치가 그 역할을 겸한다).

### 7.6 4:4 전투 (5스텝)

- 맵은 그날의 시드로 결정된다. 맵과 상대는 `pre_battle` 에서 미리 공개된다.
- 상대팀도 정확히 `TEAM_SIZE = 4` 명이다.
- 1단계(프로토타입): 일차에 맞게 스케일링된 랜덤 생성 팀.
- 2단계(Bazaar 방식): N일차 전투의 상대는 기록된 다른 유저의 N일차 시점 팀 스냅샷. 상대는 AI가 조종하므로 비동기 PvP가 된다. 프로토타입에서는 자기 과거 육성 기록의 고스트를 로컬에 저장해 같은 방식으로 검증한다.
- 고스트 데이터가 쌓이기 전에는 생성 팀, 쌓인 뒤에는 **같은 일차의 고스트**와 싸운다. 인원이 4명이 아닌 고스트(구버전 저장)는 상대 풀에서 제외한다.

### 7.7 스킬

- 스킬은 직업별 풀에서 습득한다. 액티브(쿨타임 기반 자동 발동)와 패시브로 나뉜다.
- 캐릭터당 최대 스킬 수: 액티브 3개, 패시브 2개. 가득 찬 상태에서 새로 배우면 같은 종류의 가장 오래된 스킬을 대체한다.
- 스킬 정의는 데이터(효과 목록)로 기술한다. 효과 종류: 피해, 회복, 상태이상, 버프/디버프, 소환, 돌진, 넉백, 정화, MP 회복.
- 광역 스킬(`enemy_area`, `line`, `ally_area`)은 예고·장판 규칙(§6.5)을 따른다. `telegraphSec` 과 `linger` 는 스킬 데이터에서 정한다.
- **광역 보장 (v0.6)**: 모든 메인 직업의 기본(분화 전) 풀에 광역 피해 스킬이 최소 1개 있다. 마법사의 시작 스킬 후보는 전부 광역(마력 폭발, 비전 폭풍)이다.
- **장판 대표기 (v0.6)**: 마법사 기본 풀에 비전 폭풍(5초 장판)과 메테오(예고 1.5초, 큰 즉발 + 4초 불길). 세부 직업에 블리자드(냉기, 6초 장판·둔화), 뇌우(전기, 6초 장판·기절 확률), 화염 비(화염). 다른 직업도 충격파(탱커)·대지 강타(버서커)·연막 단검(암살자)·화살비(궁수)·폭발탄(저격수)·정령 폭발(소환사)·심판의 빛(힐러) 등 기본 풀 광역을 갖는다.
- **위력 기준 (v0.6)**: 단일 주력기 1회 피해는 같은 일차 상대 최대 HP 의 18~30%, 광역 즉발은 대상당 12~20% + 장판. 보조 성격 스킬(방패 타격, 응징, 돌진 등)은 8~13%. 스킬 설명 문구는 스펙 값에서 자동 생성되므로 수치와 항상 일치한다.
- 분화 시 세부 직업 스킬 1개를 자동 습득하고, 세부 직업 전용 풀이 상점에 추가된다.
- 직업 분화 선택지는 해당 캐릭터의 세 세부 직업이 카드 3장으로 동시에 제시된다. 플레이어가 고른 카드가 곧 분화 방향이다.
- 예시:
  - 화염 마법사: 화염구(단일), 화염 폭풍(광역, 예고 0.8초 + 불길 장판), 불꽃 갑옷(패시브 반사)
  - 그림자 암살자: 은신(3초 무적시야), 급습(은신 중 공격 시 치명 확정), 연막(패시브 회피 증가)
  - 신관: 치유(단일 대량), 광역 치유(즉시, 표시용 영역 0.4초), 축복(패시브 아군 저항 증가)

### 7.8 팀 시너지

- 특정 조건을 만족하면 발동하는 팀 단위 버프.
- 획득 경로: 로그라이크 선택지, 또는 특정 직업 조합 시 자동 부여 `[제안]`.
- 직업 수(`job_count`) 조건은 4인 팀에 맞춰 **2명 이상** 기준으로 낮춘다. 3명 이상 조건은 남겨도 되지만 발동 확률이 매우 낮다.
- 예시: 탱커 + 힐러 인접 시 탱커 방어 +10%, 마법사 2인 이상 시 시전속도 +15%, 암살자 + 어둠 맵 시 은신 지속 +2초.

## 8. 완성 후 콘텐츠

- **PvP**: 다른 유저의 완성 팀(4명)과 대전. 결정론적 시뮬레이션이므로 서버가 시드만 정해주면 양측이 동일한 결과를 본다.
- **고스트 데이터**: 육성 중 매 일차의 4:4 전투 직전 팀 스냅샷을 저장한다. 다음 육성에서 같은 일차의 상대로 사용된다(Bazaar 방식). 프로토타입은 로컬 저장, 이후 서버 업로드로 확장.
- **PvE 레이드**: 점수 경쟁. 예: 보스 상대 딜량 경쟁, 웨이브 방어 생존 시간 등. 몬스터 인원이 1~8로 유연해졌으므로 웨이브형 콘텐츠와 단독 보스 콘텐츠 모두 같은 시뮬레이션으로 만들 수 있다.
- 프로토타입 범위에서는 PvP는 "저장된 두 팀 데이터로 전투 실행"으로 대체한다.

## 9. 프로토타입 계획 (웹 브라우저)

### 9.1 기술 스택 (확정)

- TypeScript + Vite. 게임 엔진 없이 Canvas 2D로 렌더링. 로직이 단순 도형 위주이므로 엔진 부담이 없다.
- 시뮬레이션 코어를 순수 TypeScript 모듈로 분리해 UI 없이도 실행(헤드리스)할 수 있게 한다. 밸런싱 시 수천 판 자동 시뮬레이션이 가능해진다.
- 프로토타입은 서버 없이 localStorage에 저장. 매 일차 팀 스냅샷을 기록해 두어 Bazaar 방식 상대 매칭을 로컬로 검증한다. 저장 구조가 바뀌면 `SAVE_VERSION` 을 올리고 버전이 다른 기존 저장 데이터는 조용히 버린다 (현재 `SAVE_VERSION = 3`). 인원이 `TEAM_SIZE` 가 아닌 저장 팀·고스트는 버전이 맞아도 버린다.
- 이후 서버 도입 시: 일차별 팀 스냅샷 업로드/조회 API만 있으면 된다. 전투는 결정론적이므로 서버가 시드만 발급하고 계산은 클라이언트가 해도 결과가 일치한다. 클라이언트 스택은 바뀌지 않는다.

### 9.2 구현 단계

1. **시뮬레이션 코어**: 캐릭터/스탯/파생수치, 결정론적 틱 루프, 이동/타겟팅 AI, 기본 공격, 4개 맵 규칙. 헤드리스로 승패 출력.
2. **관전 화면**: Canvas 렌더링, HP 바, 배속, 결과 화면.
3. **육성 루프**: 캐릭터 풀 생성, 4명 선택, 10일 × 5스텝 진행, 몬스터 전투, 하루 마무리(보너스/스킬 상점), 로그라이크 선택지.
4. **스킬과 직업 분화**: 직업별 스킬 풀, 세부 직업 9×3.
5. **팀 시너지, 저장/불러오기, 팀 간 대전(PvP 대체)**.
6. **밸런싱 도구**: 헤드리스 대량 시뮬레이션으로 직업/맵 승률 표 출력.
7. **v0.5**: 4인 팀 전환, 몬스터 1~8인 대열 생성, 광역 예고·회피·장판(Zone) 과 그 렌더, 보정.

## 10. 미결 사항

- 스탯 수치 범위와 파생 공식은 전부 제안값. 헤드리스 시뮬레이션으로 밸런싱 필요.
- 전투 제한시간과 시간 초과 시 판정 규칙.
- 스킬 상점의 가격 체계와 보너스 포인트 양.
- 몬스터 난이도별 목표 승률(95~100 / 80 / 50%) 달성을 위한 `powerScale` · `derivedMult` 보정값. 특히 1기 보스와 8기 떼를 같은 난이도 안에 넣는 보정.
- 희귀도별 효과 크기와 몬스터 보상 포인트의 균형. 몬스터 보상이 4:4 전투 보상을 압도하지 않아야 한다.
- 광역 피해 계수 상향 폭(1.15~1.3배)의 최종값. 예고 도입으로 광역 직업(마법사·대검사)이 약해지지 않았는지 확인.
- 회피 이동이 대열을 무너뜨려 오히려 손해가 되는 경우(힐러가 아군에서 멀어짐 등)의 처리.

몬스터 난이도 (육성 표본 40회 × 시드 그룹 3개 = 난이도별 1,200판, 표준 성장 정책)

| 난이도 | 승률 | 목표 | 인원 1~2 / 3~4 / 5~8 | 평균 전투 시간 |
|---|---|---|---|---|
| 하급 | 98.8% | 95~100% | 99.0 / 97.2 / 100.0 | 47초 |
| 중급 | 81.9% | 80% | 81.6 / 83.3 / 78.1 | 50초 |
| 고급 | 50.1% | 50% | 49.5 / 47.9 / 51.8 | 55초 |

시드 그룹 하나만 보면 ±5%p 정도 흔들린다. 판단은 세 그룹을 합친 값으로 한다. 고급의 일차별 승률은 1일차 52%, 10일차 52%로 평평하다.

4:4 전투 (시드 5, 200판): 10일차 승률 53% 대 46.5%, 평균 69초. 1일차 50.5% 대 49.5%, 평균 65초.
스킬 피해 비중: 10일차 68% (기본 공격 29.5%, 소환물 2.5%), 1일차 약 48%. 목표 55~70% 충족.
주력기 1회 피해: 베기 19%, 저격 21%, 급습 30%, 강타 19%, 마력 폭발 17%, 비전 폭풍 14% + 장판 17%, 메테오 27% + 장판 22%.
광역 회피: 판단력 80·민첩 70 유닛 실전 회피율 67~68%, 판단력 30·민첩 30 유닛 27~29%.
선택지 등급별 순 스탯 상승: 일반 14 / 레어 27 / 에픽 47 / 전설 80. 전부 기준 구간 안.
직업 승률은 전 직업 35~65% 범위 안 (10일차 암살자 최저 약 40%, 마법사 최고 약 58~62%).

주요 보정 상수 (`src/core/data/monsters.ts`): `TIER_POWER_RATIO` 하급 0.82 / 중급 0.855 / 고급 1.011, `DAY_DIFFICULTY_EXPONENT` 하급 0.30 / 중급 0.28 / 고급 0.37. 기본 공격 속도 상수 `BASIC_ATTACK_SPEED_BASE = 0.6`, HP 공식 `600 + 체력² × 0.95 + 직업 보정 × 3` (`src/core/stats.ts`).
