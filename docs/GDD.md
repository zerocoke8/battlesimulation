# 이능 5:5 전투 시뮬레이션 — 게임 기획서 (v0.3)

작성일: 2026-09-15
상태: 핵심 방향 확정. `[제안]` 표시는 밸런싱 등으로 바뀔 수 있는 수치 제안값. v0.2에서 세부 직업, 분화 1회 보장, 맵별 승리 조건, 상대팀 방식, 기술 스택이 확정됨.

---

## 1. 개요

- 장르: 관전형 팀 육성 시뮬레이션 (풋볼 매니저 26 모바일의 관전 방식 + 우마무스메식 육성 + 로그라이크 선택지)
- 세계관: 이능이 존재하는 판타지 세계. 5인 팀이 맵 위에서 실시간으로 싸운다.
- 플레이어 역할: 전투 중 개입 없음. 전투 전후의 육성 선택으로만 팀을 만든다.
- 육성 목표: 10사이클의 육성을 거쳐 5인 팀을 완성한다.
- 완성된 팀의 용도: 다른 유저의 완성 팀과 PvP, 점수 경쟁 레이드 등 PvE.
- 계승/인자 같은 영구 성장 요소는 없다. 육성은 매번 완전히 초기화된다.
- 검증 방식: 웹 브라우저 기반 시뮬레이터로 먼저 검증한다.

---

## 2. 핵심 루프

```
[가챠 풀에서 5명 선택]
        │
        ▼
┌──────────────── 사이클 (×10) ────────────────┐
│ 1) 전투 (맵은 사이클마다 랜덤)               │
│ 2) 전투 보너스 지급 (승리 시 많이, 패배 시 적게) │
│    → 보너스로 스킬 구매 등 성장 선택          │
│ 3) 로그라이크 선택 ×3 (3지선다)              │
└─────────────────────────────────────────────┘
        │
        ▼
[팀 완성] → PvP / PvE 레이드에 사용
```

- 전투에서 져도 진행은 계속된다. 승패는 보너스 양에만 영향을 준다.
- 사이클 중 직업 분화, 스킬 습득, 팀 시너지가 결정되므로 같은 시작 5명이라도 매번 다른 팀이 된다.

## 3. 직업 체계

### 3.1 메인 직업군 (9종)

| 메인 직업 | 역할 | 세부 직업 (확정) |
|---|---|---|
| 검사 | 근접 딜/브루저 | 대검사(광역), 쾌검사(속공), 마검사(마법 부여) |
| 탱커 | 전열 방어, 어그로 | 철벽(방패 방어), 가시갑옷(반사), 도발자(어그로 집중) |
| 버서커 | 근접 폭딜, 체력 소모형 | 광전사(체력 낮을수록 강함), 피의 계약자(흡혈), 파괴자(방어 무시) |
| 암살자 | 은신, 후방 침투, 단일 폭딜 | 그림자 암살자(은신), 독 암살자(지속 피해), 환영 암살자(분신) |
| 궁수 | 중거리 지속 딜 | 속사 궁수(연사), 정밀 궁수(치명), 함정 궁수(설치물) |
| 저격수 | 장거리 단발 고화력 | 관통 저격수(직선 관통), 마탄 저격수(마법탄), 감시자(시야/디버프) |
| 마법사 | 원거리 광역/제어 | 화염(광역 폭딜), 전기(연쇄/마비), 냉기(둔화/빙결) |
| 소환사 | 소환물로 전선 형성 | 야수 소환사(근접 소환물), 정령 소환사(원거리 소환물), 사령술사(적 시체 활용) |
| 힐러 | 회복, 지원 | 신관(직접 회복), 드루이드(지속 회복/자연), 결계사(보호막/버프) |

### 3.2 직업 분화 규칙

- 시작 시에는 메인 직업만 갖는다. 세부 직업은 육성 중 로그라이크 선택지로 분화한다.
- 분화 선택지는 4~6사이클 사이에 각 캐릭터마다 1회 보장 등장한다. 세 세부 직업 중 하나를 고른다. (확정)
- `[제안]` 분화 후에도 "직업 변경" 선택지가 낮은 확률로 등장한다. 다른 세부 직업 또는 다른 메인 직업으로 변경할 수 있으나 스탯 일부를 잃는다.
- 세부 직업은 고유 스킬 1~2개와 스탯 보정을 갖는다.

## 4. 스탯 체계

풋볼 매니저처럼 카테고리로 묶고, 각 스탯은 1~100 범위 `[제안]`. 이 스탯을 조합해 실제 전투 수치(데미지, 체력 등)를 계산한다.

### 4.1 기본 스탯 (5카테고리, 총 24개)

**신체**
| 스탯 | 설명 |
|---|---|
| 체력 | 최대 HP의 기반 |
| 근력 | 물리 공격력, 넉백 저항 |
| 민첩 | 공격 속도, 회피 |
| 이동속도 | 맵 위 이동 속도 |
| 지구력 | 전투 시간이 길어질 때 스탯 감소 저항 (FM의 체력 개념) |

**정신** (AI 행동 판단에 영향)
| 스탯 | 설명 |
|---|---|
| 판단력 | 스킬 사용 타이밍, 타겟 선택의 정확도 |
| 용기 | 체력이 낮아도 후퇴하지 않는 성향 |
| 침착 | 피격/디버프 상태에서의 스탯 저하 저항 |
| 협동 | 아군 근처에 있을 때 시너지 발동 확률과 위치 선정 |
| 집중 | 치명타 확률, 스킬 시전 중단 저항 |

**기술**
| 스탯 | 설명 |
|---|---|
| 명중 | 공격 적중률 |
| 회피 | 공격을 피할 확률 |
| 방어기술 | 물리 피해 감소 |
| 치명 | 치명타 배율 |
| 숙련도 | 스킬 쿨타임 감소, 스킬 위력 |

**이능**
| 스탯 | 설명 |
|---|---|
| 마력 | 이능 공격력 |
| 마력량 | 최대 MP |
| 마력회복 | 초당 MP 회복 |
| 시전속도 | 스킬 시전 시간 단축 |
| 저항 | 이능 피해 감소, 상태이상 저항 |

**맵 적응도** (4개, 각 1~100)
| 스탯 | 설명 |
|---|---|
| 평원 | 평원 맵 적응도 |
| 어둠 | 어둠 맵 적응도 |
| 사막 | 사막 맵 적응도 |
| 빙하 | 빙하 맵 적응도 |

### 4.2 파생 전투 수치 (기본 스탯에서 계산) `[제안 공식, 밸런싱 대상]`

| 전투 수치 | 공식 |
|---|---|
| 최대 HP | 300 + 체력² × 0.8 + 직업 보정 × 3 (체력에 초선형. 전투 시간 60~120초 목표에 맞춰 조정됨) |
| 물리 공격력 | 근력 × 1.0 + 숙련도 × 0.3 |
| 이능 공격력 | 마력 × 1.0 + 숙련도 × 0.3 |
| 물리 방어 | 방어기술 × 0.8 + 체력 × 0.2 |
| 이능 방어 | 저항 × 0.8 + 침착 × 0.2 |
| 공격 속도 | 기본 1.0 × (1 + 민첩 / 200) |
| 이동 속도 | 기본 3.0 × (1 + 이동속도 / 150) |
| 치명타 확률 | 집중 × 0.4 % |
| 치명타 배율 | 150 % + 치명 × 0.5 % |
| 적중률 | 70 % + (명중 − 상대 회피) × 0.3 % (하한 30%, 상한 100%) |
| 맵 보정 | 해당 맵 적응도 50 기준. (적응도 − 50) × 0.4 % 를 전투 수치 전체에 곱연산 (최대 ±20%) |

| 최대 MP | 50 + 마력량 × 2 |
| MP 회복 | 초당 1 + 마력회복 × 0.08 |
| 시전 속도 | 1 + 시전속도 / 200 (배율) |
| 쿨타임 감소 | 숙련도 × 0.4 % (상한 40%) |

- 피해 공식: `피해 = 공격력 × 스킬 계수 × (100 / (100 + 방어)) × 맵 보정 × 치명 배율`
- 맵 보정은 최대 HP, 공격력, 방어, 공격 속도, 이동 속도에 곱해진다. 확률과 사거리에는 적용하지 않는다.
- 빙결 상태의 대상은 받는 피해 +25%.
- 지구력: 전투 30초 경과 후부터 초당 지구력 기반으로 스탯이 서서히 감소한다. 지구력 100이면 감소 없음.

### 4.3 직업별 성장 성향

- 각 메인 직업은 스탯별 성장 계수(0.5~1.5)를 갖는다. 같은 선택지를 골라도 마법사는 마력이, 검사는 근력이 더 오른다.
- 세부 직업 분화 시 성장 계수가 한 번 더 보정된다.

## 5. 맵

맵은 사이클마다 랜덤으로 결정된다. 각 맵은 지형 특성과 승리 조건을 가진다.

| 맵 | 특성 | 유리한 직업 | 승리 조건 (확정) |
|---|---|---|---|
| 평원 | 개활지. 장애물 없음. 시야 넓음 | 저격수, 궁수, 마법사 | 상대 전멸 |
| 어둠 | 시야 반경 축소. 은신 효과 증가 | 암살자, 소환사 | 상대 전멸 |
| 사막 | 지구력 소모 2배. 이동속도 저하 | 탱커, 힐러, 버서커 | 상대 전멸 또는 제한시간 종료 시 잔여 HP 합 비교 |
| 빙하 | 이동 시 미끄러짐(경로 오차). 냉기 이능 강화 | 냉기 마법사, 검사 | 중앙 거점 점령 (일정 시간 점유) 또는 전멸 |

- 맵 적응도는 육성으로 올릴 수 있다. 캐릭터는 초기 적응도가 랜덤하게 분포되어 있어 가챠 단계에서 차별점이 된다.
- 맵 크기 `[제안]`: 40 × 30 단위. 양 팀은 좌우 끝에서 시작한다.

## 6. 전투 시뮬레이션

### 6.1 기본 구조

- 실시간 이동 전투. 맵 위에서 캐릭터가 이동하며 자동으로 판단하고 싸운다.
- 결정론적 시뮬레이션: 시드값 + 양 팀 데이터가 같으면 누구의 기기에서 재생해도 완전히 동일한 결과가 나온다.
  - 시뮬레이션 로직은 고정 틱(예: 초당 20틱)으로 돌고, 렌더링과 분리한다.
  - 난수는 시드 기반 PRNG만 사용하고, 부동소수점 순서 문제를 피하기 위해 연산 순서를 고정한다.
  - 전투 기록은 `시드 + 팀 데이터`만 저장하면 재생 가능하다. 공유 및 리플레이가 쉽다.
- 틱 레이트: 초당 20틱 고정.
- 배속: 1배, 2배, 4배, 스킵 지원. 배속은 틱 진행 속도만 바꾸고 시뮬레이션 결과에는 영향이 없다.
- 소환물은 전멸 판정에 포함되지 않는다. 소환사가 죽어도 소환물은 지속시간까지 남는다.
- 지구력 감소: 30초 이후 초당 감소, 감소량은 (100 − 지구력)/100 에 비례하고 맵의 지구력 소모 배율을 곱한다. 총 감소 상한 30%.
- 전투 시간: 완성 팀 기준 평균 1~2분. 초반 육성 단계는 HP가 낮아 더 빨리 끝난다. `[제안]` 제한시간 3분, 초과 시 맵별 규칙으로 판정.

### 6.2 AI 행동

캐릭터 AI는 직업 기본 행동 + 정신 스탯의 영향으로 결정된다.

- 직업 기본 행동: 탱커는 전진하여 적 근접, 암살자는 우회하여 후방 딜러 노림, 힐러는 아군 뒤에서 체력 낮은 아군 회복, 저격수는 최대 사거리 유지 등.
- 판단력: 높을수록 최적 타겟(체력 낮은 적, 위험한 적)을 고른다. 낮으면 가장 가까운 적을 친다.
- 용기: HP 30% 이하일 때 후퇴 여부를 결정.
- 협동: 아군 근처 위치 선정 및 시너지 스킬 발동 확률.

### 6.3 관전 화면

- FM26 모바일처럼 단순한 원형 아이콘 + 직업 심볼로 캐릭터를 표시한다.
- 화면 요소: 맵, 캐릭터 아이콘, HP 바, 스킬 발동 이펙트(간단), 경과 시간, 킬 로그, 배속 버튼.
- 전투 후 결과 화면: 승패, 킬/데스, 딜량, 힐량, MVP.

## 7. 육성 시스템

### 7.1 시작: 가챠와 팀 선택

- 가챠로 뽑은 캐릭터 풀에서 5명을 직접 고른다.
- 프로토타입에서는 랜덤 생성된 캐릭터 풀(예: 30명)을 미리 마련해 두고 그중 5명을 고르는 방식으로 대체한다.
- 캐릭터 생성 요소: 메인 직업, 초기 스탯(직업 성향 기반 랜덤), 초기 맵 적응도(랜덤 20~80), 성장 성향(랜덤 소폭 편차 0.85~1.15), 초기 스킬 1개, 등급(스탯 총합 기반 1~5성, 표시용).
- 프로토타입 풀 크기: 24명. 9개 직업이 최소 2명씩 포함된다.

### 7.2 사이클 구성

한 사이클은 다음 순서로 진행된다.

1. **전투**: 랜덤 맵에서 상대팀과 전투.
   - 1단계(프로토타입): 사이클 수에 맞게 스케일링된 랜덤 생성 팀.
   - 2단계(Bazaar 방식): N사이클째 전투의 상대는 서버에 기록된 다른 유저의 N사이클 시점 팀 스냅샷. 상대는 AI가 조종하므로 비동기 PvP가 된다. 프로토타입에서는 자기 과거 육성 기록의 스냅샷을 로컬에 저장해 같은 방식으로 검증한다.
2. **전투 보너스**: 승리 시 보너스 포인트 대량, 패배 시 소량. 보너스 포인트로 다음을 할 수 있다.
   - 스킬 구매 (직업 스킬 상점, 스킬당 60~150 포인트 `[제안]`)
   - 스탯 소폭 성장 (30 포인트에 한 스탯 +4 `[제안]`)
   - 로그라이크 선택지 리롤 (사이클당 1회, 40 포인트 `[제안]`)
   - 포인트 양 `[제안]`: 승리 120, 무승부 80, 패배 50. 사이클이 진행될수록 소폭 증가.
3. **로그라이크 선택 ×3**: 매번 3개의 선택지가 제시되고 하나를 고른다.

10사이클 종료 시 팀이 완성된다.

### 7.3 로그라이크 선택지 종류

| 종류 | 예시 | 비고 |
|---|---|---|
| 단일 대폭 성장 | A의 근력 +15 | |
| 다수 소폭 성장 | A, B의 민첩 +6 | |
| 트레이드오프 | A, B, C 각 +8, D는 체력 −6 | 이득이 큰 대신 누군가 손해 |
| 도박형 | 70% 확률로 A 마력 +20, 실패 시 −5 | 실패 가능 |
| 스킬 습득 | A가 새 스킬 습득 | 직업에 맞는 스킬 풀에서 |
| 직업 분화 | A를 화염/전기/냉기 중 하나로 분화 | 4~6사이클 사이 1회 보장 |
| 직업 변경 | A를 다른 직업으로 변경, 스탯 −10% | 낮은 확률 등장 |
| 맵 적응 훈련 | 팀 전체 사막 적응도 +8 | |
| 팀 시너지 | A와 B가 인접 시 공격력 +10% 시너지 획득 | |
| 희생형 | A가 스킬 1개를 포기하는 대신 팀 전체 스탯 +5 | 다른 캐릭이 무언가를 포기 |

- `[제안]` 선택지 등장 가중치는 사이클 후반으로 갈수록 대형 성장/시너지 비중이 높아진다.
- `[제안]` 도박형 선택지의 성공 확률은 화면에 표시한다.

### 7.4 스킬

- 스킬은 직업별 풀에서 습득한다. 액티브(쿨타임 기반 자동 발동)와 패시브로 나뉜다.
- 캐릭터당 최대 스킬 수: 액티브 3개, 패시브 2개. 가득 찬 상태에서 새로 배우면 같은 종류의 가장 오래된 스킬을 대체한다.
- 스킬 정의는 데이터(효과 목록)로 기술한다. 효과 종류: 피해, 회복, 상태이상, 버프/디버프, 소환, 돌진, 넉백, 정화, MP 회복.
- 분화 시 세부 직업 스킬 1개를 자동 습득하고, 세부 직업 전용 풀이 상점에 추가된다.
- 직업 분화 선택지는 해당 캐릭터의 세 세부 직업이 카드 3장으로 동시에 제시된다. 플레이어가 고른 카드가 곧 분화 방향이다.
- 예시:
  - 화염 마법사: 화염구(단일), 화염 폭풍(광역), 불꽃 갑옷(패시브 반사)
  - 그림자 암살자: 은신(3초 무적시야), 급습(은신 중 공격 시 치명 확정), 연막(패시브 회피 증가)
  - 신관: 치유(단일 대량), 광역 치유, 축복(패시브 아군 저항 증가)

### 7.5 팀 시너지

- 특정 조건을 만족하면 발동하는 팀 단위 버프.
- 획득 경로: 로그라이크 선택지, 또는 특정 직업 조합 시 자동 부여 `[제안]`.
- 예시: 탱커 + 힐러 인접 시 탱커 방어 +10%, 마법사 3인 이상 시 시전속도 +15%, 암살자 + 어둠 맵 시 은신 지속 +2초.

## 8. 완성 후 콘텐츠

- **PvP**: 다른 유저의 완성 팀과 대전. 결정론적 시뮬레이션이므로 서버가 시드만 정해주면 양측이 동일한 결과를 본다.
- **고스트 데이터**: 육성 중 매 사이클 전투 직전의 팀 스냅샷을 저장한다. 다음 육성에서 같은 사이클의 상대로 사용된다(Bazaar 방식). 프로토타입은 로컬 저장, 이후 서버 업로드로 확장.
- **PvE 레이드**: 점수 경쟁. 예: 보스 상대 딜량 경쟁, 웨이브 방어 생존 시간 등.
- 프로토타입 범위에서는 PvP는 "저장된 두 팀 데이터로 전투 실행"으로 대체한다.

## 9. 프로토타입 계획 (웹 브라우저)

### 9.1 기술 스택 (확정)

- TypeScript + Vite. 게임 엔진 없이 Canvas 2D로 렌더링. 로직이 단순 도형 위주이므로 엔진 부담이 없다.
- 시뮬레이션 코어를 순수 TypeScript 모듈로 분리해 UI 없이도 실행(헤드리스)할 수 있게 한다. 밸런싱 시 수천 판 자동 시뮬레이션이 가능해진다.
- 프로토타입은 서버 없이 localStorage에 저장. 매 사이클 팀 스냅샷을 기록해 두어 Bazaar 방식 상대 매칭을 로컬로 검증한다.
- 이후 서버 도입 시: 사이클별 팀 스냅샷 업로드/조회 API만 있으면 된다. 전투는 결정론적이므로 서버가 시드만 발급하고 계산은 클라이언트가 해도 결과가 일치한다. 클라이언트 스택은 바뀌지 않는다.

### 9.2 구현 단계

1. **시뮬레이션 코어**: 캐릭터/스탯/파생수치, 결정론적 틱 루프, 이동/타겟팅 AI, 기본 공격, 4개 맵 규칙. 헤드리스로 승패 출력.
2. **관전 화면**: Canvas 렌더링, HP 바, 배속, 결과 화면.
3. **육성 루프**: 캐릭터 풀 생성, 5명 선택, 10사이클 진행, 보너스/스킬 상점, 로그라이크 선택지.
4. **스킬과 직업 분화**: 직업별 스킬 풀, 세부 직업 9×3.
5. **팀 시너지, 저장/불러오기, 팀 간 대전(PvP 대체)**.
6. **밸런싱 도구**: 헤드리스 대량 시뮬레이션으로 직업/맵 승률 표 출력.

## 10. 미결 사항

- 스탯 수치 범위와 파생 공식은 전부 제안값. 헤드리스 시뮬레이션으로 밸런싱 필요.

## 11. 프로토타입 현황 (2026-09-15)

### 실행 방법
```
npm install
npm run dev          # 브라우저 http://localhost:5173
npm run headless -- --games 200 --seed 5 --cycle 10   # 대량 시뮬레이션
npm run headless -- --determinism                       # 결정론 검증
npm run headless -- --growth --seed 1                   # 10사이클 육성 헤드리스 검증
```

### 구현 완료 범위
- 9.2 구현 단계 1~6 전부 1차 구현. 직업 9종 × 세부 27종, 스킬 약 90종, 맵 4종, 로그라이크 선택지 10종, 시너지, 저장/불러오기, 고스트 스냅샷, 완성팀 대전, 헤드리스 밸런싱 도구.
- 결정론 검증 통과 (같은 시드 → 프레임 단위 동일).

### 현재 밸런스 스냅샷 (헤드리스, 랜덤 생성 팀 기준)
- 사이클 1 평균 전투 시간 약 59초, 사이클 10 약 65~75초. 목표(60~120초) 하한 근처.
- 직업 승률 35~65% 범위 안. 마법사·힐러가 하위권, 소환사·탱커·버서커가 상위권.
- 빙하 맵은 거점 점령 종료가 약 10~15%, 나머지는 전멸.

### 다음 과제
- 실제 플레이 후 보너스 포인트 경제(스킬 가격, 포인트 양) 조정. 헤드리스 기본 정책으로는 사이클 10 상대가 플레이어보다 강한 경향.
- 마법사/힐러 AI와 스탯 상향, 암살자 생존율(약 26%) 개선.
- 전투 시간을 목표 중앙값(90초)에 가깝게 조정.
- 관전 화면 연출 보강 (스킬 이펙트, 결과 화면).
